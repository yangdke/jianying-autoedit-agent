# 剪映搭建与写入后审计

## 搭建

1. 确认当前草稿名称和自动保存状态；已有草稿先备份，结构性重剪使用新版本。
2. 导入蓝图列出的素材。按 `source_in/source_out` 逐段切出并删除弃用区间，不只用一条连续视频覆盖全片。
3. 先完成画面粗剪，再处理局部加速、动作切点和段落呼吸。抽查厨房、餐厅/餐区、客厅、露台、次卧、卫生间、主卧等主要场景在时间线上的真实先后与时长；连续进房动作不得被过度切碎。
4. 生成或导入配音，每句对应一个 narration beat。必要时拆分音频，以便移动句子和画面对齐。具名房间的配音与字幕必须等画面真正进入或清楚揭示后再开始；可以延后句子或适度减缓语速，不能让“主卧”等字幕先于画面出现。
5. 配音完成后生成剪映智能字幕，先修正专名、数字、单位和断句，再使用“文本 → 智能包装”美化字幕。房产和产品讲解优先选择简洁、高级、低干扰的包装；包装不能改变事实内容或制造错误断句。
6. 预览包装后的开头、中段和结尾。字幕超出安全区、遮挡关键空间、动画过强、颜色不清楚或样式前后不统一时，重新生成一次或回退为白字黑边统一字幕。
   包装生成新字幕层后，立即检查并关闭包装前的旧基础字幕轨。抽查开头、中段、结尾至少三个时刻，确认同一句没有旧字幕与包装字幕重叠；不要误删智能包装自身的关键词强调层。
7. 最后从剪映音乐库加入纯音乐，按旁白退位并在结尾淡出。

## 写入后读回

剪映操作是有状态写入。每个重大阶段后必须观察时间线和预览，不以“点击过按钮”当作成功：

- 视频轨应存在多个与蓝图片段相符的边界；若仍是一条贯穿全片的长片段，应回到粗剪。
- 逐个跳到 narration beat 的开始、中间、结束，确认画面场景正确。
- 对具名空间额外检查 beat 开始前后约 1 秒：字幕不得在门外、走廊或前一房间提前出现。若素材顺序是“次卧 → 卫生间”，时间线和口播也保持该顺序，并给更长、更完整的卫生间镜头足够展示时间。
- 随机抽查至少开头、中段、结尾三条智能字幕，确认对象可编辑、时间码跟随声音，并且智能包装已实际应用到预期字幕。
- 检查智能包装没有改坏文字、数字和单位，没有将字幕推离底部安全区，也没有持续遮挡房屋布局、窗景或设施细节。
- 音乐轨必须有真实素材块和波形；试听旁白段与无旁白段，确认音乐存在且退位自然。
- 时间线结尾由最后一帧画面决定；删除音乐或配音造成的多余黑尾。
- 最后 12 秒逐秒查看一次，确认交通段和总结段持续有有效运动画面。交通信息可使用道路素材并在需要时回访不同有效区间；房屋总结应回访口播对应的空间，不允许末帧冻结。
- 保存后确认草稿更新时间变化，再导出新版本文件。

## 完整审片

先静音观看一次，判断画面本身是否按空间/流程讲得通；再关闭字幕正常试听一次，判断配音清楚、BGM 存在且不抢声。对房产视频重点检查：

```text
厨房旁白 → 厨房画面
餐厅/餐区旁白 → 餐桌或明确餐区画面
客厅旁白 → 客厅画面
露台/海景旁白 → 露台或真实海景
卫生间旁白 → 卫生间
次卧旁白 → 已有证据支持的次卧
主卧旁白 → 已有证据支持的主卧
```

如果某段错配，优先移动对应源区间或旁白；如果无法确认卧室身份，修改字幕/旁白为“其中一间卧室”，不能自信误标。

导出后用固定间隔抽帧复核字幕层数，并对最后 12 秒逐秒抽帧。若同一语句出现“旧基础字幕＋智能包装字幕”重复，或连续两秒以上仅为无意图的同一静止末帧，应返回草稿修复并重新导出。
