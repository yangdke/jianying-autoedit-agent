# macOS 剪映执行与验证

仅在当前主机为 macOS、或用户明确要求准备 Mac 工作流时读取本文件。语义看片、场景蓝图、声画对齐和验收标准仍以主 `SKILL.md` 及其他引用文档为准；本文件只规定 macOS 执行差异。

## 首次运行检查

1. 确认安装的是 macOS 版剪映专业版；若当前地区只提供 CapCut Desktop，先读取实际界面再映射功能，不能假设所有中文功能名称或曲库都存在。
2. 在 Codex/ChatGPT 桌面端启用 Computer Use。需要实际操作剪映时，macOS 必须授予“屏幕录制”和“辅助功能”权限；若系统或剪映请求访问“桌面”“文稿”“下载”或外置磁盘，只批准本次素材所在的必要范围。
3. 确认 `python3`、`ffmpeg`、`ffprobe` 可在终端解析；优先使用 `PATH`，不要把 Homebrew、Intel Mac 或 Apple Silicon 的安装路径写死。工具不在 `PATH` 时可向跨平台脚本传入 `--ffmpeg` 与 `--ffprobe`。
4. 打开剪映并读取当前应用名称、版本、登录状态、项目名和自动保存状态。已有草稿先在应用内复制或另存新版本，不直接编辑草稿数据库。

## macOS 操作原则

- 根据当前可见控件、菜单名称和预览结果操作，不使用未经验证的屏幕坐标。剪映升级、窗口缩放、中文/英文界面都会改变布局。
- 优先点击可见按钮；确需快捷键时使用 macOS 的 `Command` 组合，并在操作后读回时间线或预览确认结果。不能把 Windows 的 `Ctrl`、盘符路径或反斜杠命令直接照搬到 Mac。
- 所有素材使用绝对 POSIX 路径。导入文件前确认剪映对该文件夹有访问权；外置磁盘不可见时，先让用户授予对应位置权限，而不是复制整盘内容。
- 原片、抽帧目录、蓝图和导出目录分开。不得覆盖原片；导出新版本时使用清楚的版本后缀。
- 对拖放、导入、字幕生成、智能包装、配音、音乐和导出等异步操作等待界面完成，并检查真实结果；看到按钮被点击不等于写入成功。

## 从蓝图搭建时间线

1. 新建或打开目标草稿，确认画幅、帧率与蓝图一致。房产视频默认沿用源素材竖屏 `9:16`，不能拉伸。
2. 通过剪映导入界面加入蓝图列出的素材。按 `source_in/source_out` 拆成独立片段，保留连续进房方向，只压缩无信息移动和重复扫拍。
3. 每完成一个主要空间就检查时间线入点与预览：餐厅必须单独识别，次卧、卫生间、主卧的顺序跟随素材，具名口播不得早于空间证据。
4. 生成配音时先寻找“小帅”。若当前 Mac 版、账号或地区没有该声音，选择最接近的年轻男声并在交付说明中记录替代项，不得静默改用女声或跳过配音。
5. 配音锁定后生成智能字幕，修正专名、数字、单位和断句，再使用“文本 → 智能包装”或当前版本的等价入口。包装完成后关闭旧基础字幕层，并抽查开头、中段、结尾不存在重复字幕。
6. 从当前剪映音乐库选择纯音乐并执行历史去重。曲库或会员状态不同于 Windows 是正常差异；选择可用替代曲目并试听，不下载或分发曲库文件。
7. 导出前保存草稿并检查更新时间。通过界面导出到用户指定的可访问目录，等待导出完成后再用 `ffprobe` 验证音视频流、时长、分辨率和旋转信息。

## 功能差异的降级顺序

| 功能 | 首选 | 可接受降级 | 不可接受 |
| --- | --- | --- | --- |
| 配音 | “小帅”年轻男声 | 最接近的自然年轻男声，并说明 | 无声跳过、错误性别未说明 |
| 智能包装 | 当前版本的智能包装 | 统一白字黑边、底部安全区 | 重复字幕、遮挡主体 |
| 音乐 | 剪映曲库未近期使用的纯音乐 | 用户有权使用的本地纯音乐 | 没有 BGM 且不说明、分发曲库文件 |
| GUI 自动化 | Computer Use 读写并验证 | 先交付蓝图，等待权限后执行 | 盲点坐标、声称未验证写入成功 |

## macOS 验收

- Computer Use 权限只覆盖完成任务所需应用与目录。
- 剪映时间线存在真实片段、配音、字幕和音乐轨；保存状态有变化。
- 随机跳转至少三个口播节点，画面、声音和字幕一致。
- 智能包装后没有残留重复基础字幕，安全区与可读性正常。
- 最后一句口播结束前持续有有效运动画面，不冻结、不黑屏。
- 导出文件可播放，`ffprobe` 检出视频流和音频流，画幅与方向正确。

如果无法在当前 Mac 上实际打开剪映或获得 Computer Use 权限，只能报告“跨平台素材分析与蓝图已完成，剪映写入未验证”，不能把计划当成已经剪好的成片。
